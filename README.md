# Ficha pública de Pluto Turres

[ Abrir la ficha de Pluto ](https://almostking.github.io/pluto-ficha/)

![QR para abrir la ficha](./assets/qr-pluto.png)

Copia independiente de la ficha pública de HuellApp, publicada mediante GitHub Pages. La ficha y sus fotografías se sirven desde este repositorio y no requieren inicio de sesión ni conexión con Supabase.

Para actualizar los datos, editar `index.html`. El QR mantiene el mismo enlace.
